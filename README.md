# Farah UGC Portfolio (Next.js + Tailwind)
1. `npm install`
2. Copy `.env.example` to `.env.local` and set your domain
3. Videos: `public/videos/work-1..4.mp4`  |  Review screenshots: replace files in `public/reviews/`
4. WhatsApp number & links: `lib/site.js`
5. `npm run dev`  /  `npm run build && npm start`

Hero height = 100svh - navbar height (`--nav-h` in `app/globals.css`).
SEO/GEO: JSON-LD in `app/page.js`, `/sitemap.xml`, `/robots.txt` (AI crawlers allowed), `/llms.txt`.
